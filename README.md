One line: the 3am text a smart fridge sends its owner — the leftovers have unionized, and the fridge voted with them.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only, no network, no randomness) writes the entry line to `/output/entry.txt` — 96 characters, inside the gate's 1–140 characters — so both grader runs write identical bytes.
